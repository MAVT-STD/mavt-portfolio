Scripting Projects

Ability System
Scripting
Player has 4 abilities: Dash, Fireball, Shield and Punch, each with its own cooldown. Server handles all damage and effect validation, client shows keybind buttons with live cooldown timers.
NPC System
Scripting
Built to complement the Ability System. NPCs patrol, chase and attack based on player proximity. Takes damage from Fireball and Punch, ignores players with Shield active. Modular enough to adapt to other combat systems.
Round System
Scripting
Multiplayer round system with lobby countdown, round timer and intermission loop. Real-time server-client sync via RemoteEvents.
DataStore System
Scripting
On join the script pulls saved data, if none is found it initializes with Money 100 and Level 1, then fires the stats to the client immediately. Autosave every 60s, PlayerRemoving on disconnect, BindToClose covers unexpected shutdowns.
Shop System
Scripting
Player starts with coins and can spend them on items that apply temporary effects. Server validates every purchase and handles effect timers. Client UI updates in real time.
Crafting System (Combinations)
Scripting
You collect items, deposit them at an ATM and the system crafts a weapon based on your combination.
